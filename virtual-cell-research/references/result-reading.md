# 读懂一次分析结果

分析完成后，先回答四个问题：**实际做了什么、与什么比较、变化有多大、证据支持到哪一步**。`scripts/explain_result.py` 从已完成的运行目录读取真实数值，生成中文解读和机器可读摘要，不重新运行模型。

## 一条命令生成中文解读

在包含 `SKILL.md` 的 Skill 根目录运行；使用 Python 3.10 或更新版本即可，不需要安装模型环境。把下面的运行目录换成你刚完成的分析目录：

```bash
python scripts/explain_result.py --run-dir local-runs/paul-gata1-model --output-dir local-runs/paul-gata1-reading
```

Windows 也可以使用 `py -3.12 scripts/explain_result.py`，后面的参数相同。输出目录必须是新目录，且父目录已经存在；重读时使用另一个名称，不覆盖旧记录。

成功后先打开 `interpretation.md`。`summary.json` 保留精确数值、输入文件哈希、解释范围和验证状态，适合后续检查或界面展示。表格和图使用到原运行目录的相对链接；分享时保留两个目录的相对位置。跨 Windows 磁盘时列出实际文件路径，不生成失效的相对链接。

## 目前支持哪些结果

| 运行结果 | 解读会直接回答的问题 | 必须保留的解释范围 |
| --- | --- | --- |
| [Kang 供体配对观测](../cases/kang-ifnb-pbmc/README.md) | 多少供体形成配对，正负变化最大的基因分别是什么 | 观测响应；以供体为生物学单位，没有运行预测模型 |
| [CellOracle KO/OE](../examples/ko_oe/README.md) | 目标基因设成多少，其他基因的平均模拟变化如何，状态位移图怎样看 | 模拟表达与投影；随机化投影是技术对照，不能当作真实扰动验证 |
| [PRnet 固定参考评估](../cases/prnet-reference-evaluation/README.md) | 预测误差是否低于零响应参照，相关系数和误差是否给出不同信息 | 固定 demo 内的参考评估；训练成员未知，没有独立验证结论 |

工具识别具体输出契约，不把任意目录中的 CSV 自动当作模型结果。只有下载记录、缺少核心源表、运行尚未完成或状态互相矛盾时，返回退出码 `2` 和可操作的错误；新建的输出目录保留 `error.json`。已有输出目录被拒绝时，旧目录不会改动。

图形失败或按条件跳过时，报告会显示原因，并保留已完成数值的解释。Kang 没有有效供体配对时，会说明配对未形成，不补造零响应、基因排名或统计结论。

## 怎样阅读结果

### 1. 先看任务、基线和尺度

“运行成功”说明相应计算完成，不能替代对研究背景的判断。观测差值、网络模拟、表达预测是不同结果。先核对供体、细胞背景、处理时间、剂量、物种、基因 ID 和来源对照，再比较数值。

Kang 响应是供体内的 `log2(1 + CPM)` 刺激减对照；CellOracle 使用内部原始计数的 log1p 与平滑尺度；PRnet 参考入口使用固定官方 demo 的归一化和 log1p 尺度。不能直接把这些差值互相比大小，也不能统一称作实验表达倍数。

### 2. 同时看正向和负向变化

中文解读分别列出有符号平均变化最大的正向与负向基因，不只展示绝对值最大的几个。某张热图恰好全是正值，不说明其他基因没有下降。

显示名可能重复。Kang 表格使用唯一 Ensembl `gene_id` 连接；不能按 gene symbol 的第一次匹配取值。CellOracle 列表排除被直接设定的目标基因，目标的变化另列，避免把强制设置本身当作下游发现。

CellOracle OE 是固定内部表达值。有些细胞原本高于该值，设定后其目标输入反而下调。报告列出设定值、分位依据和这类细胞数；“运行 OE”不代表所有细胞的目标表达都增加。

### 3. 与简单参照比较，再讨论预测能力

PRnet 报告从逐表达谱源表重算平均 RMSE、MAE、Pearson，并核对原验证记录。RMSE 反映幅度误差，Pearson 反映线性方向一致性；正相关可以与高于零响应参照的误差同时存在。逐表达谱的更好／更差计数只是描述性比较，不是疗效排名或显著性检验。

恒定零响应没有可定义的 Pearson，报告保留“未定义”。不能把缺失相关系数补为零，也不能只展示处理后表达的高相关而忽略扰动响应误差。

### 4. 看清重复单位和验证状态

供体配对中的细胞数不等于独立生物学重复数；模型多次噪声采样也不是重复实验。跨供体 SD 不等于置信区间，状态位移大于一次随机投影不等于模型准确或机制成立。

本解读入口只处理上述当前契约，并保留未独立验证状态。独立评估需要另外说明训练与测试的关系、实际划分、基线、适用指标和统计单位；可使用[预测评估入口](prediction-evaluation.md)准备比较，不通过修改状态字段把演示结果变成独立证据。

## 核对范围和资源限制

输入按 UTF-8 读取，检查重复 JSON 字段、源表表头、稳定 ID、有限数值及关键记录的一致性。已有产物哈希会重新核对；未记录原哈希时只登记本次读取值。该检查不验证记录编写者的身份，也不证明哈希来自独立第三方。

每个 JSON 上限 4 MiB、每张解压后源表上限 32 MiB 或 100,000 行、每个被读取或核对的产物上限 256 MiB。超限会明确停止。工具不会执行运行目录里的代码、加载模型或解压后执行文件，也不逐项重算所有原始表达矩阵。

本入口已对真实 Kang、PRnet、CellOracle KO 与 OE 运行目录生成解读，核对源表数值与本地链接；这些是结果阅读与工程一致性检查，原分析的科学验证状态保持不变。

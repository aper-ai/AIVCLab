# 本轮图集的数值与图形复核

本轮图集在 2026-11-13 完成实际数据下载、处理、模型执行及绘图。随后由未编写对应实现的审查 Agent 直接读取原始来源文件和完整运行矩阵，独立计算以下项目，并打开最终 PNG 检查标题、坐标、图例、共同尺度及裁切。复核没有调用绘图函数代替独立数值计算，没有修改源结果。

## 复核的范围

这是数据、计算产物与图表的一致性检查，不是外部同行评审或独立生物学验证。审查没有重新处理 Airway FASTQ 或重新验证作者 FPKM，没有重新运行 PRnet 神经网络，也没有重新拟合 CellOracle 网络或独立实现其投影算法。Kang 的原始计数复核覆盖首页使用的全部 CD14+ 供体条件，未重新聚合其他细胞类型。

模型真实执行由各案例的本轮命令、日志与原生产物记录；独立数值复算用于检查这些产物怎样进入图表。模型运行成功、数值一致性和预测是否有效分别判断。当前图集仍保留同研究评价、训练重叠未知、单次随机化参照和缺少独立真实扰动验证等限制。

# JUN 敲除公开历史样例

AIVC-Skill 的 CellOracle 0.20.0 示例采用 GSE198291。上游同一历史批次包含多个条件，本结果包提取 JUN 敲除条件作为独立的工作台浏览视图。原报告记载质控后有 703 个细胞，JUN 条件设定值为 0，目标基因平均变化为 −2.584。

| 指标 | 原报告值 |
| --- | ---: |
| 位移幅度 | 0.581 |
| 随机对照 | 0.290 |
| 向量差长度 | 0.518 |

上游勘误保留了这些历史数值和图片，未按修正规则重跑。结果无独立实验或留出数据验证。向量差长度描述两组投影差异。
